About

This web application is designed to help users find and apply for healthcare assistance programs. It provides a centralized platform where individuals can explore available programs based on their needs, such as financial aid, medical support, or eligibility criteria.

Users can search for programs using filters, view detailed program information, and submit applications directly through the system. The application also allows administrators to manage users and track submitted applications efficiently.

The system is built using Flask (Python) for the backend, MySQL for database management, and HTML/CSS for the user interface. It demonstrates key database concepts such as relational schema design, data retrieval using SQL joins, data insertion through web forms, and dynamic query-based search functionality.

This project was developed as part of a Database Management Systems course to showcase practical implementation of database-driven web applications.
